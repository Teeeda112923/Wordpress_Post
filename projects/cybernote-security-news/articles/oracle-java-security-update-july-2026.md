## 何が公表されたのか

Oracleは2026年7月のCritical Patch Updateで、Java SE向けに19件の修正を公開しました。そのうち17件は、認証なしで悪用できる場合があります。ただし攻撃条件は脆弱性ごとに異なり、導入しているだけで被害が発生するわけではありません。

## 対象となるJavaバージョン

IPAが対象として挙げているのは、Java SE 26.0.1、25.0.3、21.0.11、17.0.19、11.0.31、8 Update 491、8 Update 491-perfです。該当する場合は、Oracleや契約ベンダーが提供する最新の修正版へ更新します。

古い業務アプリでは更新後に動作が変わる場合があります。事前に互換性を検証し、すぐ更新できない環境はネットワーク分離やアクセス制限でリスクを下げてください。

## 想定される影響

悪用された場合、アプリの異常終了、情報の閲覧や変更、端末やサーバーの制御につながるおそれがあります。ネットワーク経由で攻撃可能な項目もあるため、外部からデータを受け取るJavaサービスは優先して確認します。

## 今すぐ確認したい3つのポイント

### Javaの利用場所を洗い出す

PC、サーバー、社内ツール、開発環境、製品に同梱されたJavaを確認します。資産管理情報と実機を照合し、把握されていない旧環境も探してください。

### 修正版を検証して適用する

提供元が案内する修正版を確認し、事前にバックアップを取得します。互換性テスト後、外部公開や重要情報を扱う環境から適用してください。

### 更新後もログを確認する

更新後はサービスのエラー、想定外の通信、設定変更を確認します。不審な挙動があれば、ログを保全して調査してください。
