# タイムズカー約660万件の個人情報漏えい、本人確認書類は約160万件｜数字の違いを整理

タイムズカーのWebシステムへの不正アクセスでは、約660万アカウントの個人情報が第三者に取得されたことが確認されています。その後の第3報で、このうち運転免許証画像など本人確認書類情報が漏えいしたアカウントは約160万件と判明しました。「660万件」と「160万件」は報道の食い違いではなく、前者が漏えいしたアカウント総数、後者が本人確認書類を含む一部の件数です。2026年10月4日時点の最新公式発表と10月1日の追記をもとに、数字の意味、対象情報、退会者向け案内、利用者が注意すべき点を整理します。

## 約660万件と約160万件は何が違う？

最も重要なのは、約660万件と約160万件が別の母数を示している点です。第2報では第三者に取得されたアカウント総数が約660万件、第3報ではその中で本人確認書類情報まで漏えいしたアカウント数が約160万件と公表されました。

両方ともパーク24とタイムズモビリティの公式発表に基づく数字で、Security NEXTが報じた約160万件も第3報と一致します。Qiitaなどで約660万件と紹介されていても矛盾ではありません。約160万件は約660万件の「別集計」ではなく、その内数です。検索や報道を見る際は、全体の漏えい件数と本人確認書類画像を含む件数を分けて確認する必要があります。

| 項目 | 2026年10月4日時点 |
|---|---|
| 漏えいしたアカウント総数 | 約660万件 |
| 本人確認書類情報が漏えいしたアカウント | 約160万件 |
| 対象 | 現会員、退会者、入会未完了者、タイムズビジネスサービス会員など |
| クレジットカード情報 | 漏えいを確認せず |
| 本件に起因する不正利用 | 現時点で確認されていない |
| 具体的な侵入手法 | 公表されていない |

約160万件で確認された本人確認書類には、運転免許証画像だけでなく、公共料金の請求書などの現住所確認書類、学生証、家族確認書類も含まれます。約660万件側では、氏名、住所、生年月日、電話番号、メールアドレス、運転免許情報、復元できない形式のパスワード、連携サービスIDなどが対象者ごとに異なる形で漏えいしています。

## 本人確認書類160万件は特に注意が必要

本人確認書類画像は、氏名や連絡先だけの漏えいより本人確認に使える情報量が多く、利用者にとって重要度の高い続報です。第3報では、対象者への個別メール案内を開始し、漏えいした詳細は外部専門機関の調査結果を踏まえて改めて案内するとしています。

現時点で本件に起因する不正利用は確認されていません。ただし、タイムズカーを装うメール、SMS、電話には注意が必要です。公式も、リンクや添付ファイルを開かず、認証情報を入力しないよう呼びかけています。[正規の送信元に見えるフィッシングの見分け方](https://www.cybernote.click/2026/10/04/no-reply-accounts-google-com-honmono/)も参考になります。

## 退会済みでも対象確認が必要

対象は現在のタイムズカー会員だけではありません。退会済み利用者、入会を申し込んだものの完了しなかった人、タイムズビジネスサービスの現会員・退会者も含まれます。10月1日の追記では、退会者向けに対象確認用の専用問い合わせフォームが案内されました。

[Gyazoの約2362万件情報流出](https://www.cybernote.click/2026/10/01/gyazo-data-breach-23-million-users-2026/)や[佐川急便の不正アクセス](https://www.cybernote.click/2026/10/04/sagawa-express-tracking-data-breach-2026/)と同様に、漏えい後は企業を装った不審な連絡への警戒を続けることが重要です。

## 原因と再発防止策はまだ調査中

不正アクセスは9月25日9時07分に検知され、9月26日7時25分までに侵入経路と攻撃元からの通信遮断が完了しています。ただし、10月4日時点でも具体的な侵入手法や悪用された脆弱性は公表されておらず、外部専門機関による調査が続いています。再発防止策は続報で公表予定です。

## まとめ

タイムズカーの情報漏えいで使われている「約660万件」と「約160万件」は、矛盾する数字ではありません。約660万件は第三者に取得されたアカウント総数で、約160万件はそのうち運転免許証画像など本人確認書類情報が漏えいしたアカウント数です。本人確認書類には現住所確認書類や学生証、家族確認書類も含まれます。対象には退会者や入会未完了者も含まれ、10月1日には退会者向け確認窓口も案内されました。利用者は公式からの個別通知を確認し、タイムズカーを装うメールやSMS、電話で認証情報やカード情報を入力しないことが重要です。
