# 【第5報】タイムズカー約663万件漏えい、原因は脆弱性悪用｜免許証等画像と会員の対策

> **【第5報まで更新】2026年10月23日更新**
> 10月23日の第5報で、外部専門機関の調査終了を受けた確定件数、原因（Webシステムの脆弱性悪用）、タイムズクラブへの影響、お見舞い、マイページでの確認方法が公表されたため、全面的に更新しました。

[パーク24](https://www.park24.co.jp/)グループの「タイムズカー」のWebシステムへの不正アクセスについて、2026年10月23日の第5報で、原因はWebシステムの脆弱性悪用と公表されました。氏名・住所などで外部送信の痕跡があったのは6,628,007件、暗号化された本人確認書類画像では1,464,800件です。会員は、マイページで自分の対象情報を確認してください。

## この記事の要点

第5報で確定した内容を5つにまとめました。外部専門機関によるフォレンジック調査（不正アクセスの痕跡を調べる調査）は、10月23日に終了しています。

- 原因は、タイムズカーのWebシステムに存在した脆弱性が悪用されたことと判断されました。
- 氏名、住所、生年月日、電話番号、メールアドレス、運転免許情報で外部送信の痕跡があったのは6,628,007件です。
- 暗号化された本人確認書類画像は、外部送信の痕跡ありが1,464,800件、アクセスのみが891,602件です。
- タイムズクラブのWebシステムへの不正アクセスも確認されました。
- 本人確認書類画像の外部送信が確認された人には、3,000円相当のお見舞いが渡されます。

## 何が起きたのか？検知から第5報までの時系列

不正アクセスは2026年9月25日に検知され、同日に対象サーバーの隔離と経路の遮断、個人情報保護委員会への報告、第1報の公表が行われました。主な経緯は次のとおりです。

| 日付 | 主な出来事 |
|---|---|
| 2026年9月25日 | 不正アクセスを検知。サーバー隔離、経路遮断、フォレンジック調査開始、個人情報保護委員会へ報告、第1報 |
| 2026年9月26日 | 侵害を受けた環境と関連環境の切り離しを完了 |
| 2026年9月28日 | 警察への相談開始、国土交通省へ一報、第2報 |
| 2026年9月29日 | 第3報。個人会員への案内開始（10月1日に退会者、10月2日に法人会員へ） |
| 2026年10月16日 | 第4報。本人確認書類画像の保有ルールを見直し |
| 2026年10月23日 | フォレンジック調査を終了し、第5報を公表 |

これまで「漏えいのおそれ」とされていた数字が、第5報で外部送信の痕跡の有無に基づく確定値に置き換わりました。

## 漏えいした情報は？確定した件数の読み方

第5報では、攻撃者がアクセスし外部へ送信した痕跡が確認されたかどうかで件数が整理されています。タイムズカーWebシステムの主な内訳は次のとおりです。

| 対象 | 件数 |
|---|---|
| 氏名、住所、生年月日、電話番号、メールアドレス、運転免許情報 | 6,628,007件 |
| 暗号化された本人確認書類画像（外部送信の痕跡あり） | 1,464,800件 |
| 暗号化された本人確認書類画像（アクセスのみ、送信痕跡なし） | 891,602件 |
| 法人会員の所属部署名 | 3,677件 |
| ハッシュ化されたパスワード | 4件 |

本人確認書類画像は暗号化して保管されていたため、送信されてもすぐに中身が見られる状態になったわけではありません。ただし同社は、将来の復号の可能性は完全には否定できないとしています。連携サービスIDは第2報の9件から4件に訂正され、WESTER IDは0件でした。

タイムズクラブWebシステムでは、タイムズクラブカード番号19,510件、連携サービスID135,436件、クレジットカード番号の下4桁28件などで外部送信の痕跡がありました。カード番号全桁とセキュリティコードは保持しておらず、不正利用のおそれはないとされています。

## 原因と二次被害は？第5報で分かったこと

原因は、Webシステムに存在した脆弱性（攻撃者に悪用されうるシステムの弱点）の悪用です。攻撃者は侵入後にシステム内の情報を探り、取得した情報を使ってデータベースとファイル領域にアクセスしていました。攻撃手法の詳細は、二次被害防止のため公表されていません。

確認された侵害経路への対策は完了しています。漏えいした情報が売買・公開された事実は確認されていません。ただし同社は、フィッシング詐欺、なりすましによる申込み、不正勧誘などのリスクを挙げ、ダークウェブを含む監視を続けるとしています。具体的な情報セキュリティ強化策とガバナンス強化策は、年内を目処に公表される予定です。

## 会員がすべき対策は？4つの行動

会員がまずすべきことは、マイページで自分の対象情報を確かめることです。次の4つを実行してください。

1. **マイページで対象情報を確認する。** 10月23日17時から、会員ごとに漏えいが確認された情報が掲載されています。リンクからではなく、公式サイトからログインしてください。
2. **なりすましの申込みや勧誘に注意する。** 運転免許情報が含まれるため、身に覚えのない契約の通知や本人確認を求める連絡に警戒します。
3. **パスワードやカード情報を求める連絡に応じない。** 公式はメール・SMS・電話でこれらを尋ねないとしています。
4. **退会済みの人は専用フォームで確認する。** 問い合わせ電話は0120-25-8924（24時間）です。

[正規の送信元に見えるフィッシングの見分け方](https://www.cybernote.click/2026/10/04/no-reply-accounts-google-com-honmono/)も参考になります。

## 企業・情シス担当者への示唆

本件の教訓は、暗号化と保有期間の両方を見直す必要があるという点です。本人確認書類画像は暗号化されたうえで会員期間中と退会後7年間保有されており、外部送信された分は将来の復号の可能性を完全には否定できないとされています。

保有するデータを減らすこと、そしてWebシステムの脆弱性管理を徹底することが、侵害時の影響を小さくします。[Gyazoの約2362万件情報流出](https://www.cybernote.click/2026/10/01/gyazo-data-breach-23-million-users-2026/)や[佐川急便の不正アクセス](https://www.cybernote.click/2026/10/04/sagawa-express-tracking-data-breach-2026/)とあわせて、自社の点検に役立ててください。

## まとめ

タイムズカーの不正アクセスは、2026年10月23日の第5報で、Webシステムの脆弱性悪用が原因と公表されました。氏名や住所などで外部送信の痕跡があったのは6,628,007件、暗号化された本人確認書類画像は1,464,800件です。タイムズクラブにも影響が及びました。画像の外部送信が確認された人には3,000円相当のお見舞いが渡されます。

会員はマイページで自分の対象情報を確認し、なりすましや不審な連絡に注意してください。今後は、年内を目処に公表される再発防止策と、お見舞いの案内を公式サイトで確認することが大切です。
