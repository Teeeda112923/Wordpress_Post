# タイムズカーで約660万件の個人情報漏えい　本人確認書類は約160万件

パーク24グループが運営するタイムズカーのWebシステムが不正アクセスを受け、約660万アカウントの情報が第三者に取得されました。9月29日に新たに明らかになった情報では、このうち運転免許証画像などの本人確認書類情報が含まれるアカウントは約160万件です。対象には現会員だけでなく退会者や入会未完了者も含まれます。クレジットカード情報の漏えいと、本件に起因する個人情報の不正利用は現時点で確認されていません。本人確認書類の内訳も新たに判明しました。本記事では、9月29日時点の最新情報と利用者が確認すべき点を整理します。

## 最新情報：本人確認書類は約160万件
9月29日に新たに判明したのは、約660万アカウントすべてで本人確認書類が漏えいしたわけではなく、その情報を含むアカウントは約160万件だった点です。対象者への個別通知も始まっています。重要な更新です。

対象書類には運転免許証画像のほか、公共料金の請求書などの現住所確認書類、学生プランの学生証、家族プランの家族確認書類などが含まれます。第2報で確認された約660万件は現会員だけでなく、退会者、入会未完了者、タイムズビジネスサービスの現・旧会員も対象です。「660万件」と「本人確認書類160万件」は別の数字として見る必要があります。

| 項目 | 9月29日時点の状況 |
|---|---|
| 漏えいしたアカウント | 約660万件 |
| 本人確認書類情報 | 約160万件 |
| クレジットカード | 漏えいを確認せず |
| 不正利用 | 本件に起因する事実を確認せず |
| 攻撃手法 | 具体的内容は未公表 |

漏えい情報には氏名、住所、生年月日、電話番号、メールアドレス、運転免許情報、本人確認書類情報、パスワード、連携サービスIDなどが含まれます。パスワードは復元できない形式で保存され、クレジットカード情報は漏えいしていないと説明されています。本件に起因する不正利用も確認されていません。利用者は個別通知で自身の対象情報を確認してください。

## 利用者が注意すべきこと
現時点で不正利用は確認されていませんが、氏名や連絡先と本人確認書類の情報が組み合わさると、本人になりすました連絡や、もっともらしいフィッシングメールに悪用される可能性があります。引き続き特に注意が必要です。

メールやSMSからパスワードやカード情報を入力せず、案内は公式サイトやアプリから確認してください。[Microsoftアカウント乗っ取りの事例](https://www.cybernote.click/2026/09/24/eviltokens-microsoft-account-takeover/)のように、正規サービスを装う誘導は見分けにくいため、メール内のリンクを直接開かないことが重要です。

## 侵入方法と原因は引き続き調査中
不正アクセスは9月25日9時07分に検知され、9月26日7時25分までに侵入経路と攻撃元からの通信が遮断されました。一方、9月29日時点でも具体的な侵入手法や悪用された脆弱性は公表されていません。原因調査は継続中です。

Webサイトの脆弱性悪用や認証情報窃取など、特定の原因を断定できる段階ではありません。外部専門機関による調査は継続中で、今後は原因や再発防止策の公表が焦点です。[セキュリティ対策評価制度](https://www.cybernote.click/2026/09/14/scs-security-assessment-2026/)や[サプライチェーン攻撃の解説](https://www.cybernote.click/2026/09/24/supply-chain-attack-npm-crowdsec/)も、企業の事故対応を整理する参考になります。

## まとめ

タイムズカーの不正アクセスでは約660万アカウントの情報が第三者に取得され、9月29日の追加情報で、運転免許証画像などの本人確認書類情報が含まれるアカウントは約160万件と判明しました。対象には退会者や入会未完了者も含まれます。一方、クレジットカード情報の漏えいや、本件に起因する個人情報の不正利用は現時点で確認されていません。利用者は個別通知を確認し、タイムズカーを装うメールやSMSから認証情報を入力しないことが重要です。具体的な侵入手法や原因はまだ公表されていないため、今後の調査結果と再発防止策の続報を確認する必要があります。
