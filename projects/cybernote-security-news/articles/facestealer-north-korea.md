# 北朝鮮のフェイススティーラーとは？知人の録画映像で偽ビデオ会議、暗号資産4億ドル超を窃取

2026年11月12日、[米司法省（DOJ）](https://www.justice.gov/)と[FBI（米連邦捜査局）](https://www.fbi.gov/)は、北朝鮮のハッカー集団がフェイススティーラー（FaceStealer）と呼ばれる手口で、過去18か月に4億ドル超の暗号資産を盗んでいたと発表しました。

知人のアカウントから届く会議の招待、こっそり録画された本人の映像、AIで作った有名人の偽動画を組み合わせ、相手を信用させてマルウェアを仕込む手口です。

FBIは攻撃に使われたクラウド基盤を押収し、被害者の映像900本以上を確保しました。本記事では、手口の流れと見抜くポイント、今日からできる対策を解説します。

## フェイススティーラー事件の概要

フェイススティーラーは、FBIが名付けた北朝鮮ハッカーによるビデオ会議詐欺の呼び名です。技術的な欠陥を突くのではなく、人の信頼につけ込んで危険な操作をさせる「ソーシャルエンジニアリング」に分類されます。相手の顔や声が本物に見えるため、セキュリティに詳しい人でもだまされやすいのが特徴です。発表内容の要点を、次の表にまとめました。

| 項目 | 内容 |
| --- | --- |
| 発表日 | 2026年11月12日（米国時間） |
| 発表機関 | 米司法省、FBI、カリフォルニア州中部地区連邦検事局 |
| 攻撃者 | 北朝鮮のハッカー集団（Sapphire Sleet、BlueNoroff、APT38など） |
| 被害額 | 過去18か月で4億ドル超の暗号資産 |
| 主な標的 | 暗号資産・Web3業界の関係者、オープンソース開発者 |
| 押収したもの | 攻撃用のクラウド基盤、被害者のウェブカメラ映像900本超 |

攻撃者の集団は、セキュリティ企業ごとにUNC1069、Dangerous Password、CryptoCore、Stardust Chollimaなど別の名前でも呼ばれています。なお、2021〜2022年ごろに報じられた、Facebookのログイン情報を盗む同名のAndroidマルウェアとは別物です。検索するときは「北朝鮮」「FBI」などの言葉を一緒に入れると、目的の情報にたどり着きやすくなります。

## 被害の規模と背景

今回の発表は、偽ビデオ会議詐欺の摘発と、暗号資産取引所Binanceから盗まれた資産の差し押さえという2つの動きをまとめたものです。被害の大きさと、北朝鮮が暗号資産を狙い続ける理由を、順を追って整理します。

### 18か月で4億ドル超、被害者映像は900本以上

米司法省によると、フェイススティーラーによる被害は過去18か月で4億ドルを超えました。

FBIが押収したクラウド基盤には、世界中の暗号資産・Web3業界で働く被害者のウェブカメラ映像が900本以上保存されていました。

この映像は、次の標的をだますための「素材」として使い回されていたとみられます。

### 北朝鮮が暗号資産を狙う理由

米司法省は、北朝鮮政府が暗号資産の窃取で得た資金を、体制の維持や違法な兵器開発に充てていると指摘しています。

経済制裁で通常の外貨獲得が難しい北朝鮮にとって、国境を越えて素早く動かせる暗号資産は格好の標的です。近年は数十億ドル規模の暗号資産が盗まれたとされています。

### Binanceから60億ドル超を盗んだ別の事件

今回の発表では、フェイススティーラーとは別の事件も取り上げられました。

2026年10月29日ごろ、FBIがTraderTraitorと呼ぶ北朝鮮の軍関係者が、暗号資産取引所Binanceから60億ドル超の資産を盗んだ事件です。発生直後の状況は、CyberNoteの[【続報】Binance不正出金、補填用に63.4億ドル確保](https://www.cybernote.click/2026/10/31/binance-hack-followup-2026-10-31/)でも紹介しています。

米政府と民間企業の協力で27億ドル超が凍結され、そのうち12億ドル超は裁判所の許可を得て差し押さえや保全が進んでいます。

## フェイススティーラーの手口

フェイススティーラーの特徴は、一度だました被害者を「次の標的をだます道具」に変え、知人から知人へと被害を広げていく点です。FBIの注意喚起をもとに、攻撃の流れを5つの段階に分けて、順番に詳しく解説します。

### ①乗っ取ったアカウントから会議に誘う

攻撃者は、すでに乗っ取った被害者のTelegramなどのチャットアカウントを使い、その人の知人に連絡します。

「近況を話したい」「協業の相談がある」「投資の話がある」といった誘い文句に、過去のやり取りの内容を織り交ぜるため、本人からの連絡だと信じてしまいます。

LinkedIn、Slack、Discordのアカウントが使われることもあります。

### ②偽のZoom・Teamsへ誘導する

次に、Calendlyなどの日程調整ツールで会議の予定を送り、開始直前になってから会議のリンクを送ってきます。

リンク先は、ZoomやMicrosoft Teamsにそっくりな偽サイトです。本物によく似た紛らわしいドメイン名が使われ、見た目では本物と区別できないよう作られていました。

### ③録画映像とディープフェイクで信用させる

偽の会議に入ると、以前の被害者をこっそり録画した映像が流されます。標的から見ると、よく知る相手が普通に会議に参加しているように見えます。

複数の映像を流して、参加者が何人もいるように装うこともあります。

さらにFBIは、攻撃者が「超知能（SI）」と呼ぶAIを使い、暗号資産業界の著名人のディープフェイク動画（AIで作った偽の映像）も会議に使っていると明らかにしました。

### ④偽の音声トラブルでマルウェアに感染させる

信用させたところで、攻撃者は「声が聞こえない」などの偽のトラブルを起こします。

そして、修正用のアップデートを促したり、スクリプトの実行やコマンドの貼り付けを指示したりします。この「修正」を実行すると、ブラウザのログイン情報を盗むツールやキーロガー（入力を記録するツール）、画面を盗み見るツール、遠隔操作用の裏口が入り込みます。

偽のリンクを開いた時点から、標的自身のウェブカメラ映像も録画されています。

### ⑤新たな被害者が次の踏み台になる

感染した端末からは、暗号資産のウォレットや復元用のシードフレーズ（ウォレットを取り戻すための秘密の単語）が探し出されます。

米司法省によると、最初の感染から数か月、長いと1年以上たってから暗号資産が盗まれたケースもありました。

乗っ取られたアカウントと録画映像は、今度はその人の知人を狙う道具として使われます。

## 米司法省・FBIの対応

米司法省とFBIは、攻撃の基盤を押さえるとともに、被害を防ぐための情報公開にも力を入れています。カリフォルニア州中部地区連邦検事局とFBIロサンゼルス支局が中心となって進めた対応の内容を、2つに分けて紹介します。

### 攻撃用のクラウド基盤を押収

FBIは連邦裁判所の令状に基づき、フェイススティーラーに使われていたクラウド基盤を押収しました。そこには被害者のウェブカメラ映像900本以上が含まれていました。

FBIロサンゼルス支局の幹部は、この手口は経験豊富な技術者やセキュリティ意識の高い人でもだまされるほど巧妙だと警告しています。

### 注意喚起レポートと特設ページを公開

FBIは同日、手口の詳細や防御策、被害時の対応をまとめたFLASHレポートを、[IC3（インターネット犯罪苦情センター）](https://www.ic3.gov/)で公開しました。

あわせて、関連情報をまとめた[FaceStealer特設ページ](https://www.fbi.gov/investigate/cyber/facestealer-cryptocurrency-theft-scheme)も開設しています。

## 利用者が気をつけたい危険サイン

フェイススティーラーは、相手の顔も声も本物に見えるため、映像だけで見抜くのはほぼ不可能です。そこで大切なのは、会議の「中身」ではなく、誘われてから会議が進むまでの「流れ」に表れる不自然さに気づくことです。攻撃の段階ごとに表れやすい危険サインを、次の表にまとめました。会議に誘われたときのチェックに使ってください。

| 段階 | 気をつけたい危険サイン |
| --- | --- |
| 誘い | 知人から突然、投資や協業、近況報告の会議に誘われる |
| 日程調整 | 予定の招待にリンクがなく、開始直前にリンクが送られてくる |
| リンク | ZoomやTeamsに似ているが、ドメイン名がどこか違う |
| 会議中 | 映像は自然なのに、会話がぎこちない、反応が遅れる |
| トラブル | 音声の不具合を理由に、アップデートやコマンド実行を求められる |
| その後 | 自分のアカウントから知人に身に覚えのない招待が届いている |

特に、会議中に「コード貼り付け」や「スクリプト実行」を求められたら、相手が誰であっても詐欺を疑うべきです。本物のZoomやTeamsが、会議中に利用者へコマンドの入力を求めることはありません。少しでも違和感があれば、その場で操作せず、いったん会議を抜けて電話など別の手段で相手に確認しましょう。気まずさより、資産と知人を守ることを優先してください。

## 偽ビデオ会議から身を守る対策

FBIは、フェイススティーラーへの備えとして、会議への参加方法やアカウントの守り方について具体的な対策を示しています。被害を未然に防ぐ対策と、被害に気づいたときの対応に分けて、順を追って詳しく紹介します。

### 被害を防ぐための対策

偽ビデオ会議による被害を防ぐには、「リンクから参加しない」「会議中に何も実行しない」という2つの原則を徹底することが近道です。加えて、アカウントの乗っ取りや資産の流出に備えておくと、万一だまされても被害を小さくできます。FBIが推奨している主な対策は、次のとおりです。できるものから取り入れましょう。

- ZoomやTeamsは公式アプリを使い、リンクではなく会議IDで参加する
- 招待した本人と会話ができるまで、自分のカメラをオンにしない
- 会議中にアップデートを促されても実行せず、会議後にアプリを別途更新する
- 招待が届いたら、電話など別の連絡手段で本人に確認する
- チャットアプリに多要素認証とログイン通知を設定する
- シードフレーズや秘密鍵を端末内に保存しない
- ブラウザのウォレットには少額だけを置き、多額の資産はハードウェアウォレットで管理する

中でも効果が大きいのは、別の手段で本人に確認する方法です。Telegramで誘われたなら電話やSMSで確認するなど、連絡が来た経路とは違う方法を使うのがポイントです。相手のアカウントが乗っ取られていれば、同じ経路で確認しても攻撃者が答えるだけだからです。親しい相手ほど確認を省きがちなので、習慣として決めておきましょう。

### 被害に気づいたときの対応

偽の会議に参加してしまった、会議中に言われるままコマンドを実行してしまったと気づいたら、被害が広がる前に、できるだけすぐ動くことが大切です。感染した端末はすでに攻撃者に監視されている可能性があるため、作業は別のきれいな端末で行いましょう。FBIが示している主な対応は、次のとおりです。上から順に進めてください。

- きれいな別の端末で新しいウォレットを作り、資産を移す
- すべてのパスワードを変更し、全端末からログアウトさせる
- チャットや開発者向けサービスのアカウントに多要素認証を設定する
- 知人や勤務先に、自分のアカウントが悪用されている可能性を伝える
- 乗っ取られたアカウントの停止や復旧をサービス運営者に依頼する
- IC3（ic3.gov）に「FaceStealer」というキーワードを添えて報告する

知人への連絡は、被害の連鎖を止めるうえで、特に重要な対応です。フェイススティーラーは、被害者のアカウントと映像を使って次の標的を狙うため、早く知らせるほど次の被害を防げます。SNSなどでの一斉告知もとても有効です。チャットアプリの乗っ取りへの対処は、[LINE乗っ取りの確認方法と対処](https://www.cybernote.click/2026/10/29/line-nottori-taisho/)も参考にしてください。

日本国内で被害に遭った場合は、最寄りの警察署や都道府県警察のサイバー犯罪相談窓口にも相談しましょう。

## 業界への教訓：開発者を狙うサプライチェーン攻撃

フェイススティーラーの標的は、暗号資産の保有者だけにとどまりません。FBIは、オープンソースソフトウェアの開発者を狙う動きが強まっていると警告しています。一人の開発者がだまされると、何百万人もの利用者に被害が及びかねません。

### 有名JavaScriptライブラリの開発者が感染

FBIによると、2026年に入って、広く使われているJavaScriptライブラリの管理者が偽のTeams会議に誘われ、感染する事例がありました。

会議には知っている顔も含めて複数の参加者がいるように見え、管理者は「修正」の指示に従ってしまいました。攻撃者はその権限を使い、週に数千万回ダウンロードされるライブラリに悪意あるプログラムを紛れ込ませたといいます。

早期に発見されて被害は食い止められ、FBIはライブラリ名を公表していません。

### 「知っている顔」を前提にしない仕組みづくり

米司法省は、開発者への攻撃をソフトウェアのサプライチェーン攻撃（信頼された開発元を経由して利用者に被害を広げる攻撃）を狙ったものとみています。FBIは、npmやRustのパッケージ開発者を狙った試みも複数確認しているとしています。攻撃の仕組みは、[サプライチェーン攻撃とは？npm汚染のCrowdSec事例と対策](https://www.cybernote.click/2026/09/24/supply-chain-attack-npm-crowdsec/)で詳しく解説しています。

今回の事件が示したのは、「顔が見えれば本人」という前提がもう通用しないということです。企業や開発チームは、個人の注意力に頼るのではなく、本人確認の手順や権限の管理を仕組みとして整えることが求められます。

## まとめ

フェイススティーラーは、乗っ取ったアカウントと被害者の録画映像を使い、知人を装った偽ビデオ会議で相手をだます北朝鮮の手口です。過去18か月で4億ドル超の暗号資産が盗まれ、FBIは攻撃基盤と被害者映像900本以上を押収しました。

相手の顔が本物に見えても、会議中にコマンド実行やアップデートを求められたら詐欺を疑いましょう。公式アプリから参加し、別の手段で本人に確認する習慣が、最も確実な防御策になります。

暗号資産を持つ人だけでなく、オープンソースの開発者や企業のセキュリティ担当者も、自分ごととして備えておきたい事件です。
