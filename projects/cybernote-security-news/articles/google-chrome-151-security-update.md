# 【重要】Google Chrome 151に370件のセキュリティ修正、今すぐ更新すべき理由

Googleは2026年7月30日、Chrome 151の安定版を公開し、合計370件のセキュリティ修正を反映しました。WindowsとMac向けは151.0.7922.71または151.0.7922.72、Linux向けは151.0.7922.71へ順次更新されます。修正にはCritical評価の7件が含まれ、細工されたHTMLページを起点にサンドボックス回避などへつながる可能性が示された問題もあります。個人利用者だけでなく、業務端末や仮想デスクトップでChromeを配布する企業も対象です。この記事では、確認できた影響、既知の悪用状況、更新後に管理者が点検すべき項目を整理します。

## Google Chrome 151のセキュリティ更新概要

今回の更新は単一の脆弱性だけを直すものではなく、ブラウザーを構成する多くの機能をまとめて更新する大型リリースです。件数の多さだけで危険度を判断せず、Criticalとされた問題の内容と、自分の端末に修正版が届いているかを分けて確認する必要があります。

### Critical評価の7件を修正

GoogleがCriticalとして示したのは、CVE-2026-17650からCVE-2026-17656までの7件です。対象領域はCompositing、Dawn、Views、Skia、Updater、ANGLE、Ozoneにまたがります。解放済みメモリの再利用、信頼できない入力の検証不足、競合状態など、攻撃者による不正処理につながり得る問題が含まれます。

特にNVDが公開したCVE-2026-17651の記録では、Android版Chrome 151.0.7922.72より前に影響し、細工されたHTMLページによってサンドボックス回避につながる可能性が説明されています。CISA-ADPのCVSS 3.1評価は9.6です。ただし、7件すべてが同じOS、同じ攻撃条件、同じ影響を持つわけではありません。

### 既知の悪用は確認されていない

確認したGoogleのリリース情報には、今回の修正が実際の攻撃で悪用されているとの記載はありません。NVDに掲載されたCVE-2026-17651のSSVC情報でも、2026年7月30日時点の悪用状況は「none」とされています。このため、攻撃が進行中、または被害が発生済みとは断定できません。

一方、悪用未確認は安全を保証する表現ではありません。Chromeはウェブ閲覧やクラウドサービス利用の入口となるため、攻撃コードの公開や脆弱性情報の詳細化より前に更新を終えることが重要です。過去に悪用が確認された事例は、[ChromeのCVE-2025-2783解説](https://www.cybernote.click/2026/07/02/202503-google-chrome-securityupdate/)でも紹介しています。

## 利用者と企業管理者が確認すること

更新操作そのものは難しくありませんが、ダウンロードだけで安心せず、再起動後のバージョン確認まで行うことが大切です。組織では自動更新の設定だけを見るのではなく、実端末へ反映された割合と、更新できない端末の理由を把握してください。

### 個人利用者は更新と再起動を行う

Chromeのメニューから「ヘルプ」「Google Chromeについて」を開くと、利用中のバージョンと更新状況を確認できます。WindowsとMacでは151.0.7922.71または151.0.7922.72、Linuxでは151.0.7922.71が今回案内された版です。配信は段階的なため、表示される最新版が環境によって異なる場合があります。

更新ファイルを取得しても、古いChromeプロセスが動き続けていれば修正が有効にならないことがあります。作業中のタブを保存したうえでブラウザーを再起動し、もう一度バージョンを確認してください。直前のCritical脆弱性との違いは、[CVE-2026-15899の解説](https://www.cybernote.click/2026/07/28/cve-2026-15899-chrome/)も参考になります。

### 企業は未更新端末を可視化する

企業管理者は、MDMや端末管理ツールでChrome 151への更新率を確認し、古い版が残る端末を抽出します。長期間オフラインのノートPC、仮想デスクトップのマスターイメージ、共有端末、更新を固定した検証環境は見落とされやすいため、通常端末とは分けて点検すると効果的です。

業務アプリとの互換性確認が必要でも、更新を無期限に延期するのは避けるべきです。例外端末には期限、責任者、代替策を設定し、検証完了後に速やかに適用します。Chromeで発生するサンドボックス回避の考え方は、[CVE-2026-7350の解説](https://www.cybernote.click/2026/07/02/%E3%80%90%E8%84%86%E5%BC%B1%E6%80%A7%E6%83%85%E5%A0%B1%E3%80%91-cve-2026-7350-google%E3%81%AEchrome%E3%81%AE%E8%84%86%E5%BC%B1%E6%80%A7%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6/)で詳しく確認できます。

## FAQ

Chrome 151の更新について判断を誤りやすい点を、公開情報に基づいて整理します。修正版の配信状況はOSや管理方法によって異なるため、番号だけを機械的に比較せず、Chromeの更新画面や組織の管理コンソールで実際の適用状態を確認してください。

### Google Chrome 151では何が修正されましたか？

Googleは計370件のセキュリティ修正を公表し、Critical評価の7件を含めています。メモリ解放後使用や入力検証不備などがあり、利用環境に合う最新版への更新が必要です。

### Chromeの更新後に何を確認すればよいですか？

Chromeの設定からバージョンを確認し、更新後にブラウザーを再起動してください。企業管理者は端末管理画面で更新率を確認し、長期間オフラインの端末も個別に点検します。

### 今回の脆弱性は実際の攻撃に悪用されていますか？

確認したGoogle公式情報には既知の悪用を示す記載はありません。NVD上のCVE-2026-17651もCISAの評価では悪用なしとされているため、攻撃確認済みとは断定できません。

## 参考情報

更新内容と修正版は[Google Chrome Releasesの公式発表](https://chromereleases.googleblog.com/2026/07/stable-channel-update-for-desktop_0887107924.html)で確認できます。一次情報として認められる[NIST NVDのCVE-2026-17651詳細](https://nvd.nist.gov/vuln/detail/CVE-2026-17651)には、対象バージョン、サンドボックス回避の可能性、CVSS、2026年7月31日までの更新履歴が掲載されています。

Googleは脆弱性の詳細を、利用者への修正版配信が進むまで制限する場合があります。記事公開後に対象OS、攻撃条件、評価が更新される可能性があるため、運用担当者は上記の一次情報を確認し、社内の対応記録にも確認日と参照URLを残してください。

## まとめ

Google Chrome 151では370件のセキュリティ修正が行われ、Critical評価のCVE-2026-17650からCVE-2026-17656までの7件が含まれます。確認できた公式情報では既知の悪用は公表されていませんが、細工されたHTMLページを通じたサンドボックス回避につながる可能性が示された問題もあり、更新を先送りする理由にはなりません。個人利用者はChromeを再起動してバージョンを確認し、企業管理者は端末管理ツールで未更新端末を抽出してください。オフライン端末、共有端末、仮想デスクトップのイメージ、更新例外端末を優先して点検し、最新版への移行完了まで追跡することが重要です。
