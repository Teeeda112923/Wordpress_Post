# 郵便局アプリで個人情報流出、19人分69件を不正取得｜ゆうID・送り状情報も対象

日本郵政と日本郵便は、スマートフォン向け「郵便局アプリ」への不正アクセスにより、ゆうIDと郵便局アプリに関連する顧客情報69件、19人分が第三者に不正取得されたと公表しました。対象には本人の氏名や住所だけでなく、住所録に登録した連絡先や、送り状の差出人・受取人情報、追跡番号、品名、発送・配達予定情報も含まれます。2026年9月25日に緊急メンテナンスを実施し、対策後の9月26日にサービスを再開しています。現時点で不正利用の形跡は確認されていませんが、対象者には書面などで個別連絡が行われる予定です。

## 郵便局アプリで確認された不正アクセス

今回の事案は「流出した可能性」ではなく、第三者による情報の不正取得が確認されたケースです。日本郵政と日本郵便は、郵便局アプリへの不正アクセスを受けて調査し、ゆうIDとアプリに保存された複数種類の情報が取得されたと発表しました。公表内容を時系列と影響範囲、対応状況などを整理すると、次のようになります。

| 項目 | 内容 |
|---|---|
| 公表日 | 2026年9月29日 |
| 影響 | お客さま情報69件・19名分を不正取得 |
| 緊急メンテナンス | 9月25日22時30分ごろから実施 |
| サービス再開 | 9月26日16時ごろ |
| 不正利用 | 公表時点で確認されていない |
| 対象者への連絡 | 書面などで個別連絡予定 |

「69件」は69人を意味する数字ではなく、公式発表は69件・19名分です。郵便局アプリの全利用者が対象になったとの発表でもありません。一方、住所録や送り状には本人以外の情報も保存されるため、人数だけで影響を小さいと判断するのは適切ではありません。対象者への個別連絡と追加発表を確認する必要があります。

## 何の個人情報が不正取得されたのか

不正取得された情報は対象者ごとに異なります。ゆうID会員の氏名、住所、電話番号、生年月日、性別、メールアドレス、勤務先情報、家族状況に加え、住所録に登録した氏名や住所、企業名、電話番号、メールアドレスなどが含まれます。本人情報だけの問題ではない点が重要です。

さらに郵便局アプリで作成した送り状では、差出人と受取人の氏名、住所、電話番号、企業名、メールアドレスのほか、追跡番号、品名、発送・配達予定情報も対象です。こうした配送情報は、郵便局を装った再配達通知や本人確認メールを本物らしく見せる材料になり得ます。

## 利用者が警戒したい二次被害

現時点で不正取得された情報の不正利用は確認されていません。ただし、氏名や住所、連絡先と配送情報が組み合わさると、「荷物を保留しています」「配達先の確認が必要です」といった偽SMSやメールの説得力が高まります。通知のリンクからではなく、公式アプリや公式サイトを自分で開いて確認することが重要です。

同様の観点は、[タイムズカーの個人情報漏えい](https://www.cybernote.click/2026/09/28/timescar-unauthorized-access-data-leak-2026/)でも共通します。また、[正規の送信元に見えるフィッシングの見分け方](https://www.cybernote.click/2026/10/04/no-reply-accounts-google-com-honmono/)も参考になります。対象者から連絡を受けた家族や取引先も、不審な配送通知に注意してください。

## 郵便局アプリは現在利用できるのか

日本郵便は2026年9月25日22時30分ごろから、ゆうIDと郵便局アプリの緊急メンテナンスを実施しました。不正アクセスの調査と必要な安全対策を行ったうえで、9月26日16時ごろにメンテナンスを終了し、サービスを再開しています。現在も停止中という状況ではありません。

ただし、調査結果や対象者への通知状況は今後更新される可能性があります。対象者には準備が整い次第、書面などで個別に連絡するとされています。連絡がまだ届いていないことだけを理由に対象外と断定せず、日本郵政と日本郵便の公式発表を継続して確認してください。

## まとめ

郵便局アプリへの不正アクセスでは、ゆうIDとアプリに関連する顧客情報69件、19名分が第三者に不正取得されたことが確認されています。対象には本人の登録情報だけでなく、住所録や送り状に記録された差出人・受取人の氏名や住所、電話番号、追跡番号、品名、発送・配達予定情報も含まれます。サービスは9月26日に再開し、公表時点で不正利用の形跡は確認されていません。ただし、配送情報と連絡先の組み合わせは、郵便局を装った偽SMSやメールを本物らしく見せる材料になります。通知のリンクを開かず、公式アプリや公式サイトから確認することが重要です。
