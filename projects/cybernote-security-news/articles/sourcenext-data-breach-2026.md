# ソースネクストで約2,252万件の情報漏洩｜原因・対象・今すぐ取るべき対策

ソースネクストは2026年10月15日、会員情報を管理するシステムが不正アクセスを受け、最大2,251万9,960件の個人情報が外部に流出した可能性があると公表しました。

流出の可能性がある情報には、メールアドレスやパスワード、氏名、住所、生年月日などが含まれます。
クレジットカード情報は対象外とされていますが、パスワードの使い回しやフィッシングによる二次被害が懸念されます。

本記事では、公式発表をもとに経緯と原因、対象となる情報、利用者が今すぐ取るべき対策、企業が学ぶべき教訓を整理します。
あわせて、本物の通知メールと偽メールの見分け方も紹介します。

## ソースネクストの情報漏洩の概要

2026年10月の事案は、会員情報を管理するシステムへの不正アクセスによるものです。
まずは公式発表で判明している事実を確認します。
ここでは発生から公表までの流れと、事案の全体像を表にまとめて押さえます。

### 何が起きたのか

[ソースネクスト株式会社](https://sourcenext.co.jp/)は、PCソフトや翻訳機ポケトークなどを販売する国内のソフトウェア企業です。
同社は2026年10月15日、自社が管理する会員情報に第三者が不正アクセスし、会員の個人情報が外部に流出したと発表しました。

不正アクセスは10月9日から始まり、10月13日に同社が検知して遮断しています。
攻撃者は会員情報を取得するためのAPIを不正に利用し、登録者の情報を抜き取ったとされています。

### 事案の要点

公式発表の内容を、利用者が判断に使う項目ごとに整理しました。
特に、パスワードが流出対象に含まれている点と、クレジットカード情報は対象外とされている点が重要です。
件数や対象となる情報は2026年10月15日時点の発表に基づくため、最新の情報は同社の公式サイトで確認してください。
表の後には、利用者が取るべき行動の考え方も補足します。

| 項目 | 内容 |
|---|---|
| 公表日 | 2026年10月15日 |
| 不正アクセスの期間 | 2026年10月9日10時頃〜10月13日13時36分（封じ込め完了） |
| 原因 | 会員情報取得APIの不正利用 |
| 流出の可能性がある件数 | 22,519,960件 |
| 主な流出情報 | メールアドレス、パスワード、氏名、住所、生年月日など |
| クレジットカード情報 | 対象外（対象システムに保存なし） |
| 対象者 | 2026年10月13日13時36分までに会員登録していた人 |
| 当局への報告 | 個人情報保護委員会へ報告済み（10月15日） |

表のとおり、今回の事案は特定の期間に買い物をした人だけでなく、会員登録をしているほぼすべての人が対象になり得ます。
過去にソフトを一度だけ購入した人や、製品登録だけをした人も含まれる可能性があります。
心当たりがある人は、通知メールの有無にかかわらず、後述する対策を早めに実施してください。
特に、パスワードを他サービスでも使っている人は優先度が高い対象です。

## 被害の規模と流出した情報

流出の可能性がある件数は2,000万件を超え、国内でも大規模な個人情報の流出事案です。
事案の深刻さを正しく把握するために、ここでは件数の規模感、流出した情報の項目、クレジットカード情報の扱い、過去の事案との関係を順に説明します。

### 流出件数は2,251万9,960件

流出した可能性がある件数は22,519,960件で、約2,252万件にのぼります。
ソースネクストは公式サイトで登録ユーザー数を約2,000万人と案内しており、会員基盤のほぼ全体に影響が及んだとみられます。

なお、公表された数字は件数であり、人数とは一致しない場合があります。
正確な人数や内訳は、外部機関による調査の結果を待つ必要があります。

### 流出した可能性のある情報

流出した可能性がある情報は、連絡先や属性情報に加え、ログインに使う認証情報まで幅広い項目に及びます。
同社によると、すべての会員について全項目が流出したわけではなく、登録状況によって対象となる項目は異なります。
自分がどの項目を登録していたかを思い出しながら、影響の範囲を確認してください。
公表された項目は次のとおりです。

- メールアドレス
- パスワード
- 氏名、氏名カナ
- 住所
- 性別
- 電話番号、FAX番号
- 生年月日
- 会社名、役職名、部署名
- システム固有の識別情報（加入サービス、登録日、ログイン日など）

メールアドレスとパスワードが同時に流出している点は、今回の事案で最も注意すべきポイントです。
同じ組み合わせを他のサービスで使っていると、第三者に不正ログインされるおそれがあります。
また、氏名や住所、勤務先の情報がそろうことで、本人をねらった巧妙な詐欺に悪用される危険も高まります。
流出したものとして、早めに対策を進めることが重要です。

### クレジットカード情報は流出していない

同社は、クレジットカード情報は不正アクセスを受けたシステムに保存されておらず、流出の対象に含まれないと説明しています。
そのため、本件を理由としたカードの利用停止や再発行は不要としています。

また、会員登録の際に運転免許証などの本人確認書類は提出させていないため、書類画像の流出もありません。
ただし、カード会社を装ったフィッシングで新たに情報を盗まれる可能性はあるため、油断は禁物です。

### 2023年にも不正アクセス被害が発生

ソースネクストは2023年2月にも、オンラインショップへの不正アクセスを公表しています。
このときは決済アプリケーションが改ざんされ、2022年11月15日から2023年1月17日までに入力された情報が窃取されました。

漏えいの可能性があったのは個人情報12万982件で、そのうちクレジットカード情報は11万2,132件です。
約3年半で再び大規模な事案が起きたことになり、件数は前回の約186倍に拡大しました。

## 不正アクセスの経緯と原因

今回の不正アクセスは、検知までに約4日間続いていました。
ここでは公式発表に記載された時系列と、原因とされる会員情報取得APIの不正利用について、技術的な観点から解説します。
詳細な手口がまだ公表されていない点についても補足します。

### 発生から公表までの時系列

公式発表に記載された主な出来事を、時系列で整理しました。
不正アクセスが始まってから検知するまでの期間と、検知から封じ込め、公表までの期間に分けて見ると、対応の流れがわかりやすくなります。
時刻はいずれも同社の発表に基づくもので、警察への被害申告は公表時点では予定の段階です。
表の後には、各期間から読み取れるポイントも補足します。

| 日時 | 出来事 |
|---|---|
| 2026年10月9日 10時頃 | 第三者による不正アクセスが始まる |
| 2026年10月13日 9時頃 | 会員情報管理システムへの不正アクセスを確認 |
| 2026年10月13日 13時36分 | 不正な通信の遮断などにより封じ込めを完了 |
| 2026年10月15日 | 個人情報保護委員会へ報告し、事案を公表 |
| 2026年10月16日（予定） | 所轄警察署へ被害を申告 |

検知から封じ込めまでは約4時間半と短い一方で、不正アクセスの開始から検知までには約4日かかっています。
この4日間に、会員情報が継続的に取得されていた可能性があります。
大量のデータが外部へ送られていたにもかかわらず、早期に気付けなかった理由は、今後の調査で明らかにされるべき点です。
続報で検知の経緯が説明されるかどうかにも注目です。

### 原因は会員情報取得APIの不正利用

同社は原因について、第三者が会員情報取得APIを不正に利用したと説明しています。
APIとは、システム同士がデータをやり取りするための窓口で、Webサイトやアプリが会員情報を表示する際などに使われます。

どのような脆弱性を突かれたのか、詳細な手口は公表されていません。
一般にAPIを悪用した情報流出では、認可チェックの不備や、一度に大量のデータを取得できる設計が原因になるケースがあります。

### パスワードの保存方式は明らかになっていない

流出した可能性のある項目にはパスワードが含まれていますが、どのような形式で保存されていたかは公表されていません。
ハッシュ化などの処理がされていれば、元のパスワードをすぐに復元されるリスクは下がります。

一方で、処理の方式によっては解析される可能性も残ります。
同社は対象のパスワードをリセットする措置を完了したとしていますが、利用者自身も流出したものとして扱い、変更しておくのが安全です。

## ソースネクストの対応

ソースネクストは、検知した当日のうちに不正アクセスを封じ込め、2日後に公表しました。
ここでは、封じ込めと当局への報告、利用者への通知、問い合わせ窓口について、発表内容を整理します。
利用者が実際に受け取る案内の内容も、あわせて確認しておきましょう。

### 封じ込めと当局への報告

同社は10月13日に不正アクセスを確認した後、外部からの不正な通信を遮断し、同日13時36分までに封じ込めを完了しました。
その後も監視を続けており、封じ込め後の不正アクセスは確認されていないとしています。

10月15日には[個人情報保護委員会](https://www.ppc.go.jp/)への報告を完了し、16日に警察へ被害を申告する予定です。
外部の専門機関と連携した詳細調査と、全システムの緊急点検も進めています。

### 利用者への通知とパスワードのリセット

対象となる可能性がある会員には、10月15日から登録メールアドレス宛てに、お詫びと案内のメールが順次送られています。
メールアドレスを登録していない会員には、郵送で連絡する予定です。

あわせて、同社は対象のパスワードを順次リセットしています。
そのため、急にログインできなくなった場合は、画面の案内に従ってパスワードを再設定する必要があります。

### 専用の問い合わせ窓口

同社は本件専用の問い合わせ窓口を設置し、土日祝日も受け付けています。
退会を希望する場合も、この窓口で手続きできます。
問い合わせ先を調べる際は、メールに書かれた番号をうのみにせず、公式サイトに掲載された情報と照合してください。
偽の窓口に誘導する詐欺もあり得るため、注意が必要です。主な窓口の情報は次のとおりです。

- 電話：0120-035-116（フリーダイヤル）
- 受付時間：10時〜18時（土日祝日を含む）
- Web：公式サイトのお問い合わせフォーム
- 参考：公式サイトのよくあるご質問ページ

窓口の番号は同社の公式発表ページに記載されています。
不審な電話やSMSで別の番号に誘導された場合は、応じずに公式ページの番号へ自分からかけ直してください。
問い合わせが集中してつながりにくいことも想定されるため、まずはよくある質問のページで答えを探すのも有効です。
電話が混み合う時間帯を避け、フォームを併用するのも一つの方法です。

## 利用者が注意すべきこと

今回の流出で最も警戒すべきなのは、流出した情報を使った二次被害です。
ここでは、自分が対象かどうかの確認方法、想定される二次被害、本物の通知メールと偽メールを見分けるポイントを解説します。
通知を受け取った人も、まだ受け取っていない人も確認してください。

### 自分が対象かどうかの確認方法

対象となるのは、2026年10月13日13時36分までにソースネクストへ会員登録していた人です。
過去にソフトを購入した人や、製品のユーザー登録をした人は、対象に含まれている可能性があります。

同社から通知メールや郵便が届いた場合は、対象者とみて対応してください。
登録した記憶があいまいな場合も、念のためパスワードの変更を済ませておくと安心です。

### 想定される二次被害

メールアドレスとパスワード、氏名や住所などの個人情報がそろって流出すると、さまざまな手口に悪用されるおそれがあります。
同社も公式発表で、関係先を装った不審なメールやSMS、電話、郵便物への注意を呼びかけています。
被害の種類を知っておくだけでも、怪しい連絡に気付きやすくなります。
生年月日や勤務先の情報も含まれるため、特に次のような被害に警戒してください。

- 同じパスワードを使う他サービスへの不正ログイン（リスト型攻撃）
- ソースネクストやカード会社を装ったフィッシングメール、SMS
- 氏名や勤務先を使った、本人あての巧妙な詐欺メール
- 偽の問い合わせ窓口やサポートを名乗る電話

なかでも被害が広がりやすいのが、他サービスへの不正ログインです。
攻撃者は流出したメールアドレスとパスワードの組み合わせを、ショッピングサイトやSNSなどで自動的に試します。
パスワードを使い回している人は、ソースネクストだけでなく、関連するすべてのサービスで対策が必要です。
金銭に関わるサービスから優先して確認しましょう。

### 本物の通知メールと偽メールの見分け方

今回は同社から本物の通知メールも送られているため、偽メールが紛れ込みやすい状況です。
メールに記載されたリンクからログインするのではなく、ブックマークや検索結果から公式サイトを開いて操作しましょう。

本件を理由にカード番号や暗証番号の入力を求めるメールは、詐欺の可能性が高いと考えてください。
同社は本件でカード情報は流出していないと説明しており、カード情報の再入力を求める理由がないためです。

## 今すぐ取るべき対策

被害を防ぐために利用者ができることは、決して難しくありません。
ここでは、ソースネクストのパスワード再設定、使い回しているサービスの対応、多要素認証やパスワード管理ツールの活用という3つの対策を紹介します。

### ソースネクストのパスワードを再設定する

まずは、ソースネクストのアカウントのパスワードを再設定しましょう。
同社は対象のパスワードをリセットしており、ログイン時に画面の案内に従って新しいパスワードを設定する仕組みになっています。

新しいパスワードは、過去に使ったものや他サービスと同じものを避けてください。
十分な長さがあり、推測されにくい文字列を設定することが大切です。

### 同じパスワードを使う他サービスも変更する

ソースネクストと同じメールアドレスとパスワードの組み合わせを、他のサービスでも使っている場合は、早急な変更が必要です。
流出したパスワードは、リスト型攻撃にすぐ使われるおそれがあるためです。
同社も公式発表で、他サービスのパスワード変更を呼びかけています。
すべてを一度に変えるのが難しい場合は、次の手順で優先度の高いサービスから対応を進めましょう。

1. 同じパスワードを使っているサービスを書き出す
2. ネット銀行、通販、決済サービスなど、金銭に関わるサービスから変更する
3. メールアカウントやSNSのパスワードも変更する
4. 各サービスのログイン履歴を確認し、身に覚えのないログインがないか調べる

メールアカウントは、他サービスのパスワード再設定に使われるため、特に優先度が高い対象です。
メールを乗っ取られると、パスワード再設定の連絡を悪用され、ほかのアカウントも次々に奪われるおそれがあります。
ログイン履歴に不審な記録があった場合は、そのサービスの窓口にも連絡してください。
ログイン履歴の確認方法は、各サービスのヘルプページで案内されています。

### 多要素認証とパスワード管理ツールを活用する

パスワードの流出に備えるには、多要素認証の設定が効果的です。
多要素認証を有効にすると、パスワードが知られても、スマートフォンへの確認コードなどがなければログインできなくなります。

また、パスワード管理ツールを使えば、サービスごとに異なる複雑なパスワードを無理なく管理できます。
今回のような流出が起きても被害を1つのサービスにとどめられるため、使い回しをやめる仕組みとして有効です。

## 企業が学ぶべき教訓

今回の事案は、会員情報を扱うすべての企業にとって他人事ではありません。
ここでは、APIのセキュリティ、大量のデータ取得を検知する仕組み、公表のタイミングと説明責任という3つの観点から教訓を整理します。

### APIは攻撃の入り口になりやすい

Webサービスやアプリの普及により、APIは多くのシステムで欠かせない存在になりました。
一方で、APIは外部から直接呼び出せるため、設計や認可の不備があると攻撃の入り口になります。

セキュリティの国際コミュニティである[OWASP](https://owasp.org/)は、APIに特有のリスクをOWASP API Security Top 10として公開しています。
自社のAPIが、利用者に必要な範囲を超えるデータを返していないか、定期的に点検することが重要です。

### 大量のデータ取得を検知する仕組みを持つ

今回の事案では、不正アクセスの開始から検知までに約4日かかりました。
2,000万件を超える情報が取得される間に気付けなかったとすれば、監視の仕組みに課題があった可能性があります。

APIの呼び出し回数やデータ量に上限を設け、通常と異なる大量取得を検知したら自動で遮断する仕組みが有効です。
ログの監視を人手に頼るだけでなく、異常を自動で知らせる体制づくりが求められます。

### 公表のタイミングと説明責任

2023年の事案では、カード会社から連絡を受けてから公表までに約40日を要しました。
今回は検知から2日後に公表しており、初動の情報公開は前回より早くなっています。

一方で、パスワードの保存方式や脆弱性の詳細など、利用者がリスクを判断するための情報はまだ不足しています。
調査の進展に合わせて続報を出し、透明性の高い説明を続けることが、信頼回復には欠かせません。

## まとめ

ソースネクストでは、会員情報取得APIの不正利用により、約2,252万件の個人情報が流出した可能性があります。

メールアドレスとパスワードも対象に含まれるため、会員登録をしている人は、同じパスワードを使っている他サービスも含めて早めに変更してください。
使い回しがある人は、金銭に関わるサービスやメールアカウントから優先して見直しましょう。
クレジットカード情報は対象外とされていますが、同社やカード会社を装ったフィッシングには引き続き注意が必要です。

原因の詳細やパスワードの保存方式は未公表のため、今後の続報も確認していきましょう。
