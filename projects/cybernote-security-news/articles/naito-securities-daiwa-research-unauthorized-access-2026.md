# 内藤証券・大和総研に不正アクセス｜最大631名の情報漏えいの可能性と対策

2026年10月15日、大和総研は、内藤証券から運用を受託しているインターネット取引システムFinancial Plate/WB4が、第三者による不正アクセスを受けたと公表しました。

攻撃は10月14日早朝の約2時間に行われ、その時間帯にログインしていた最大631名の個人情報が漏えいした可能性があります。対象には証券口座番号や出金先の銀行口座情報も含まれています。

現時点で不正出金や不正取引は確認されていませんが、漏えいした情報を使ったなりすまし連絡には警戒が必要です。本記事では公表内容をもとに、事案の概要と技術的なポイント、利用者が今すべきことを整理します。

## 内藤証券・大和総研の不正アクセス事案の概要

今回の事案は、証券会社が自社で運用するシステムではなく、外部に運用を委託していたネット取引システムで起きました。委託先と委託元の関係を押さえておくと、公表内容が理解しやすくなります。まずは関係する組織と、公表された基本情報を確認します。

### 公表の経緯と関係する組織

公表したのは、大和証券グループのシンクタンク兼システム会社である[株式会社大和総研](https://www.dir.co.jp/)と、委託元の[内藤証券株式会社](https://www.naito-sec.co.jp/)です。両社は2026年10月15日に、それぞれ事案を公表しました。

Financial Plate/WB4は、大和総研が証券会社向けに提供しているインターネット取引システムです。共同利用型と個社利用型の2形態があり、複数のネット証券会社が採用しています。

ただし今回の公表で被害が示されたのは、内藤証券向けの環境のみです。同じシステムを使う他の証券会社への影響は、公表時点で触れられていません。

### 事案の基本情報

大和総研の発表によると、不正アクセスを受けたのは内藤証券のインターネット取引システムのWebサーバーです。攻撃は早朝の時間帯に約2時間10分続き、ログイン中の利用者の状態を一時的に保持するデータベースにアクセスされました。

利用者が少ない早朝を狙ったのか、偶然なのかは明らかにされていません。公表された主な事実関係は次のとおりです。

| 項目 | 公表内容 |
| --- | --- |
| 公表日 | 2026年10月15日 |
| 公表元 | 大和総研／内藤証券 |
| 対象システム | Financial Plate/WB4（内藤証券向け） |
| 発生日時 | 2026年10月14日 4時46分〜6時56分 |
| 攻撃を受けた箇所 | Webサーバー、一時データベース |
| 影響の可能性 | 攻撃時間帯にログインしていた最大631名 |
| 業務用データベース | 不正アクセス・情報取得の痕跡なし |
| 侵入経路 | 調査中 |

631名という数字は、漏えいの可能性がある最大人数です。全員の情報が実際に持ち出されたと確定したわけではありません。

また、資産状況や取引内容を保管する業務用データベースには被害の痕跡がないとされており、影響範囲は一時データベースに限られる見込みです。攻撃時間帯にログインしていなかった利用者は、現時点の公表内容では対象に含まれていません。

## 被害の内容と背景

漏えいの可能性がある情報には、連絡先だけでなく金融機関の口座情報も含まれます。直接の金銭被害は確認されていないものの、悪用のされ方次第では二次被害につながりかねません。ここでは対象となる情報の中身と、証券業界で不正アクセスが続いている背景を見ていきます。

### 漏えいの可能性がある情報

対象は、攻撃が行われた時間帯にネット取引システムへログインしていた利用者です。一時データベースには、ログイン状態の維持に使う情報として、本人を特定できる項目や口座に関する項目が保持されていました。

パスワードや暗証番号は含まれていませんが、個人を特定できる情報と金融情報がそろっている点が特徴です。大和総研が公表した情報項目は以下のとおりです。

- 氏名
- 住所
- 電話番号
- メールアドレス
- 証券口座番号
- 勤務先
- 出金先の金融機関名・支店名・口座番号

両社は、これらの情報だけでは証券口座へのログインや取引はできないと説明しています。

ただし、氏名と連絡先、証券口座番号、出金先口座がひとまとまりで知られると、本物の証券会社を装った連絡の信ぴょう性が一気に高まります。勤務先が含まれる点も、職場を装った連絡などに悪用されるおそれがあります。直接の金銭被害よりも、二次被害への備えが重要です。

### 不正出金・不正取引は確認されていない

大和総研によると、公表時点では漏えいした情報の不正利用や、不正な出金・取引の被害は確認されていません。

一方で、調査は継続中です。影響範囲の特定が進めば、対象者や情報項目が変わる可能性もあります。続報が出た場合は、公式サイトで最新情報を確認してください。

### 証券業界で続く不正アクセスの背景

証券口座を狙った攻撃は、2025年春から急増しました。金融庁によると、偽サイトで盗まれたログイン情報による不正アクセスと不正取引が多発し、業界全体で認証強化が求められてきました。

内藤証券自身も、過去に顧客の意図しない口座ログインや不正取引を確認したとして、利用者に注意を呼びかけています。金融庁の公表では、2026年8月時点でも4社で不正取引25件が発生しており、被害は完全には収まっていません。

なお、10月5日には大和証券も、問い合わせ管理を委託していた外部サービスへの不正アクセスを公表しています。社名が似ていますが、今回の大和総研の事案とは別件です。

## 技術的なポイント：一時データベースが狙われた意味

今回アクセスされたのは、顧客情報を恒常的に保管する業務用データベースではありませんでした。それでも重要な情報が漏えいした可能性がある点に、今回の事案の特徴があります。一時的な保存領域が狙われたことで、どのようなリスクが生じたのかを解説します。

### Webサーバー経由で一時データベースにアクセス

ネット取引システムでは、利用者がログインしている間、その状態を保持する仕組みが必要です。今回の一時データベースは、このログイン状態（セッション）を管理する役割を担っていたとみられます。

攻撃者はWebサーバーを入口にして、この一時データベースにアクセスしました。そのため、影響を受けたのは攻撃が行われた約2時間に、たまたまログインしていた利用者に限られています。

大和総研の対応内容に不正なプログラムの削除が含まれていることから、Webサーバー上に何らかの不正なプログラムが設置されていたことがうかがえます。

### 一時データにも重要情報が含まれていた

注目すべきは、一時的な保存領域にも出金先の口座番号や勤務先まで保持されていた点です。一時データベースは業務用データベースより短命な分、保護の優先度が低く見られがちです。

しかし実際には、取引画面の表示や処理の高速化のために、多くの顧客情報がセッション側に置かれることがあります。今回の事案は、一時データであっても漏えいすれば十分に被害につながることを示しています。

### 侵入経路は調査中

攻撃者がどのような手段でWebサーバーに侵入したのかは、公表時点で明らかになっていません。脆弱性の悪用なのか、認証情報の不正利用なのかも不明です。

大和総研は外部の専門機関にフォレンジック調査を依頼しており、原因の究明を進めています。侵入経路については推測で判断せず、続報を待つ必要があります。

## 大和総研と内藤証券の対応

大和総研は、事象の判明後すぐにシステムの提供先である内藤証券と連携して初動対応を行いました。攻撃の翌日には公表しており、対応のスピードも注目点です。ここでは実施済みの対応と、今後の方針、問い合わせ窓口をまとめます。

### 判明後の初動対応

大和総研の発表によると、事象の判明後ただちに、攻撃の遮断と被害拡大の防止に向けた対応が取られています。なりすましによる被害を防ぐため、利用者のログイン状態も一時的に解除されました。

あわせて、外部の専門機関によるフォレンジック調査も始まっており、原因と影響範囲の特定が進められています。公表された主な対応は次のとおりです。

- 不正なプログラムの削除
- 攻撃元からの通信の遮断
- 防御設定の強化
- なりすまし防止を目的としたログイン状態の一時的な解除
- 外部専門機関によるフォレンジック調査の依頼
- 原因および影響範囲の調査

攻撃は10月14日の早朝に発生し、翌15日には公表されています。発生からわずか1日で事実関係を公表した点は、利用者が早めに警戒できるという意味で評価できます。

一方、侵入の原因や具体的な再発防止策は今後の発表を待つ段階です。ログイン状態の解除によって利用者は再ログインが必要になったため、その際も公式サイトやアプリから操作するよう注意してください。

### 今後の対応と問い合わせ窓口

大和総研は、外部の専門機関と連携して原因の究明と影響範囲の特定を進め、再発防止策を講じるとしています。新たに判明した事実は、速やかに公表する方針です。

内藤証券も、影響の可能性がある顧客には調査結果を踏まえて個別に連絡するとしています。不安がある場合は窓口に相談できますが、問い合わせ先は利用者の立場によって異なります。

| 対象 | 問い合わせ先 |
| --- | --- |
| 内藤証券の顧客 | 内藤証券 お客様相談室（06-4803-6520、平日9時〜17時） |
| Financial Plate/WB4を利用する証券会社等 | 大和総研 カスタマーコンタクトセンター（03-6365-6775、平日9時〜17時） |
| 報道機関 | 大和総研 経営企画部 広報担当（03-5620-5429） |

内藤証券の口座をお持ちの方は、大和総研ではなく内藤証券の窓口へ問い合わせるのが基本です。大和総研の窓口は、システムを利用する証券会社など法人向けに設けられています。

問い合わせの際は、検索結果やメールに記載された番号ではなく、公式サイトに掲載されている連絡先を使ってください。偽の窓口に誘導される被害を防ぐためです。

## 内藤証券の利用者が注意すべきこと

漏えいの可能性がある情報だけでは口座にログインできないものの、詐欺の材料としては十分に使えます。自分が対象かどうかわからない段階でも、念のため警戒しておくことが大切です。利用者が特に気を付けたいポイントを整理します。

### なりすまし連絡に警戒する

情報漏えいの後は、被害者を狙った詐欺が増える傾向があります。氏名や証券口座番号、出金先口座を知っている相手からの連絡は、本物だと信じてしまいやすいため注意が必要です。

特に、お詫びや補償の案内を装う手口は、漏えい事案の直後に多く見られます。本物そっくりの文面で届くこともあるため、次のような連絡には特に気を付けてください。

- 内藤証券を名乗り、パスワードや暗証番号を尋ねるメール・電話・SMS
- お詫びや補償を口実に、リンク先で情報入力を求める連絡
- 出金先口座の変更や本人確認を急がせる連絡
- 公式とは異なる電話番号やURLへの誘導

相手が口座番号などを正しく伝えてきても、それだけで正規の担当者だと判断しないことが大切です。内藤証券も、メールや電話でパスワードなどを尋ねることはないとしています。

少しでも不審に感じたら、連絡に記載された番号やリンクは使わず、公式サイトに掲載された窓口へ自分から問い合わせてください。家族にも同様の注意を共有しておくと安心です。

### 口座と出金先を定期的に確認する

念のため、取引履歴や出金先口座の登録内容に身に覚えのない変更がないかを確認しましょう。メールアドレスなどの登録情報が勝手に変更されていないかも、あわせて見ておくと安心です。

異常を見つけた場合は、すぐに内藤証券の窓口へ連絡し、パスワードを変更してください。出金先の銀行口座についても、不審な入出金がないか通帳やアプリで確認しておくと安心です。

## 証券口座を守るための予防策

今回の事案に限らず、証券口座を狙った攻撃は今後も続くと考えられます。内藤証券の利用者以外にとっても、自分の口座を見直すよい機会です。金融庁の注意喚起をもとに、すべての利用者が取り組みたい基本的な対策を紹介します。

### 金融庁が推奨する基本対策

金融庁は、証券会社のインターネット取引サービスを利用するすべての人に向けて、偽サイトや不正ログインへの注意を繰り返し強く呼びかけています。

ログインIDやパスワードの窃取、不正取引の被害はどの証券会社でも起こり得るとしたうえで、利用者自身が日頃から実践できる具体的な対策として、次のような項目を挙げています。

- メールやSMSに記載されたリンクは、見覚えのある送信者でも開かない
- 証券会社のサイトは、事前に登録したブックマークからアクセスする
- 多要素認証や取引・出金の通知サービスを有効にする
- パスワードを使い回さず、推測されにくいものにする
- 口座の状況をこまめに確認する

いずれも特別な知識がなくても今日から実践できる対策です。特にブックマークからのアクセスは、メールやSMSのリンクから偽サイトへ誘導される被害を防ぐうえで効果があります。

不審なサイトに情報を入力してしまった可能性がある場合は、すぐに証券会社の窓口へ連絡し、パスワードを変更してください。早めに動くほど、被害を食い止められる可能性が高まります。

### 多要素認証と通知設定を有効にする

金融庁は2025年10月に監督指針を改正し、証券会社にフィッシングに耐性のある多要素認証の必須化を、2026年6月末までに対応するよう求めました。多くの証券会社で、ログイン時の追加認証が標準になりつつあります。

利用者側でも、証券会社が提供する認証機能や通知サービスをすべて有効にしておくことが重要です。万が一パスワードが漏れても、追加の認証があれば不正ログインを防げる可能性が高まります。

## 今回の事案から読み取れる業界への教訓

今回の事案は、証券会社やシステム運用を受託する企業にとっても見過ごせない論点を含んでいます。金融業界に限らず、会員システムを外部に委託している企業にも共通する課題です。委託先管理とデータ管理の観点から、確認しておきたい教訓を整理します。

### 委託先が運用するシステムも自社の責任範囲

今回攻撃を受けたのは、内藤証券ではなく大和総研が運用するシステムでした。しかし利用者から見れば、自分の情報を預けた相手は内藤証券です。

委託先で起きたインシデントでも、委託元は顧客対応や説明の責任を負います。2026年10月は委託先経由の情報漏えいが相次いでおり、委託先のセキュリティ水準を契約時だけでなく継続的に確認する重要性が高まっています。

### セッション・キャッシュ層のデータ最小化

一時データベースに出金先口座まで保持されていた点は、同種のシステムを運用する企業にとって重要な確認ポイントです。ログイン状態の維持に本当に必要な項目は何か、改めて見直す価値があります。

保持する項目を減らせば、万が一侵入されても漏えいの影響を小さくできます。今回の公表内容から考えられる確認事項は次のとおりです。

- セッション管理用のデータベースやキャッシュに、必要以上の個人情報を置いていないか
- 一時データにも、業務用データベースと同等の保護や監視をかけているか
- インシデント発生時に、全利用者のログイン状態を一括で解除できるか
- 特定の時間帯にログインしていた利用者を、ログから素早く特定できるか

今回の大和総研は、攻撃時間帯のログイン利用者を最大631名と特定し、ログイン状態の解除も実施しました。こうした対応は、平時からログの保全や手順の整備ができていてこそ可能になります。

自社で同じ状況が起きたときに同じ対応ができるか、委託先も含めて点検しておくことが求められます。机上演習などで手順を確かめておくと、いざというときに迷わず動けます。

### 迅速な公表と影響範囲の特定

今回の事案では、攻撃の翌日に委託先と委託元の両社が公表しました。影響を受けた可能性がある人数と情報項目を具体的に示したことで、利用者は自分が警戒すべきかを判断しやすくなっています。

インシデント対応では、原因がすべて判明する前でも、わかっている事実を早めに伝えることが二次被害の防止につながります。委託先と委託元の間で、公表の役割分担や連絡手順を事前に決めておくことが重要です。

## まとめ

内藤証券のネット取引システムFinancial Plate/WB4への不正アクセスでは、最大631名の氏名や連絡先、証券口座番号、出金先口座の情報が漏えいした可能性があります。

公表時点で不正出金や不正取引は確認されておらず、これらの情報だけで口座にログインすることもできません。ただし、なりすまし連絡に悪用されるおそれがあるため、内藤証券の利用者は不審なメールや電話に十分注意してください。

侵入経路は調査中のため、今後の続報で原因と再発防止策がどう示されるかにも注目が集まります。証券口座を持つすべての人は、この機会に多要素認証や通知設定を見直しておきましょう。
