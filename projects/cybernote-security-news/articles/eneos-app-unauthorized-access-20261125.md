# ENEOS公式アプリが使えない｜不正アクセスで停止、給油の支払いと偽メールへの注意点

ENEOS公式アプリは、2026年11月25日16時ごろからサービスが止まっています。
アプリのシステムで第三者による不正アクセスが見つかり、被害の拡大を防ぐために運営元のENEOS（[公式サイト](https://www.eneos.co.jp/)）が停止しました。

ガソリンスタンドは通常どおり営業しており、現金やクレジットカード、タグ型EneKeyで給油できます。
一方、アプリでの支払い（モバイルEneKey）とアプリのクーポンは使えません。

個人情報が漏れたかどうかは、11月25日時点ではまだ調査中です。
いま最も警戒したいのは、この騒ぎに便乗した偽のメールやSMSです。
ENEOSを名乗る連絡に書かれたリンクは開かないでください。

## ENEOS公式アプリの不正アクセスとは

今回の件は、ENEOSが自社のスマートフォンアプリで不正アクセスを検知し、アプリ全体を止めたというものです。
ここでは、11月25日の発表に書かれていることと、書かれていないことを分けて整理します。
あわせて、アプリがどれだけ多くの人に使われているかも確認します。

### 11月25日に発表された内容

ENEOSは2026年11月25日、「ENEOS公式アプリへの不正アクセス検知による利用停止について（お詫び）」を公表しました。
発表の中身は、アプリを止めたことと利用者への影響が中心で、原因や漏えいの有無はまだ書かれていません。
発表文は短く要点だけが書かれているため、11月25日時点で公表されている事実を、次の表に項目ごとにまとめます。

| 項目 | 11月25日時点の公表内容 |
|---|---|
| 発表日 | 2026年11月25日 |
| 起きたこと | 公式アプリのシステムで第三者による不正アクセスを検知 |
| 停止の開始 | 2026年11月25日（水）16時ごろ |
| 停止の目的 | 被害の拡大を防ぎ、お客さま情報の漏えいの有無などを確認するため |
| 使えないもの | アプリで配信されたクーポン、モバイルEneKey |
| 使えるもの | 現金、クレジットカード、タグ型EneKeyでの支払い |
| 漏えいの有無 | 調査中 |
| 再開の時期 | 安全性を確認し、見通しが立ち次第ウェブサイトなどで案内 |

表のとおり、何が漏れたのか、何件なのか、どこから入られたのかは、まだ発表されていません。
被害の件数や漏れた情報の種類は、ENEOSの調査が進むにつれて続報で明らかになる見込みです。
この記事の内容も11月25日時点のもので、続報によって変わる可能性があります。
新しい発表があれば、表の内容も更新します。

### ENEOS公式アプリとはどんなアプリか

ENEOS公式アプリは、全国のENEOSのガソリンスタンドで使える給油用のアプリです。
スマートフォンに二次元コードを表示して支払う機能や、クーポン、ポイントカードとの連携、洗車や車検の予約などがそろっています（[App Storeの説明](https://apps.apple.com/jp/app/id1612229796)）。

利用者はとても多く、会員数は2026年6月に2,100万人を突破しました（[ENEOSの発表](https://prtimes.jp/main/html/rd/p/000000125.000039980.html)）。
車を使う人の多くが入れているアプリが止まったため、影響を受ける人の数も大きくなります。

## 被害・影響：使えなくなったものと使えるもの

利用者がいちばん困るのは、ガソリンスタンドでのアプリ払いとクーポンが使えないことです。
給油そのものは止まっていませんが、支払い方法によっては店頭で戸惑うかもしれません。
個人情報への影響はまだわかっていないため、確定していることと調査中のことを分けて見ていきます。

### 給油はできる、アプリ払いとクーポンは使えない

給油そのものは止まっていません。
燃料の供給や販売に影響はないとENEOSは説明しており、ガソリンスタンドは通常どおり営業しています。
ただし、アプリにひもづく支払い方法や特典は一時的に使えないため、店頭で戸惑わないよう、支払い方法ごとに使えるかどうかを次の表にまとめます。
出かける前に確認しておきましょう。

| 支払い・特典 | 11月25日時点 |
|---|---|
| 現金 | 使える |
| クレジットカード | 使える |
| タグ型EneKey（キーホルダー型） | 使える |
| モバイルEneKey（アプリの二次元コード払い） | 使えない |
| アプリで配信されたクーポン | 使えない |

ふだんアプリの二次元コードで支払っている人は、しばらく現金かクレジットカードを用意しておくと安心です。
キーホルダー型のタグ型EneKeyを持っている人は、そちらを使う方法もあります。
クーポンの有効期限が停止中に切れた場合の扱いは、まだ案内されていないため、再開時の案内を確認してください。
セルフ式のスタンドでも、現金やカードでの給油はふだんどおりに行えます。

### 個人情報の漏えいは「調査中」

利用者が最も気になるのは、自分の情報が漏れたかどうかでしょう。
11月25日時点では、漏えいの有無も、対象となる人や情報の種類も発表されていません。

アプリには、氏名（カナ）や生年月日、ポイントカードの連携情報、車の情報などを登録できます。
クレジットカードを登録すると二次元コードで支払える仕組みもあります。
ただし、これらの情報が今回の不正アクセスで見られたかどうかは、まったくわかっていません。
「漏れた」と決めつけず、続報を待ちながら、できる備えだけ先に済ませておくのが現実的です。

## 原因・技術解説：わかっていることと、わかっていないこと

不正アクセスの原因や侵入の方法は、11月25日時点でまだ公表されていません。
ここでは、現時点でわかっていないことを確認したうえで、なぜ情報が少ない段階でアプリを止めたのか、その考え方を専門用語をなるべく使わずに説明します。

### 侵入経路は公表されていない

どこから、どのような方法で入られたのかは、11月25日時点で明らかになっていません。
アプリ本体の弱点を突かれたのか、アプリとつながる裏側のシステム（サーバー）が狙われたのか、外部の委託先が関係しているのかも不明です。

SNSなどで原因をめぐる推測が出回ることがありますが、公式の発表がないうちは事実として扱わないほうが安全です。
CyberNoteでも、続報で原因が示されたら追記します。

### 情報が少ない段階でアプリを止める理由

不正アクセスを見つけたとき、まず「つながりを切る」のは被害を広げないための基本の手順です。
攻撃者がシステムの中にとどまっていると、時間がたつほど見られる情報が増えたり、別のシステムに入り込まれたりするおそれがあります。

アプリを止めると、利用者は不便になります。
それでも止める判断をしたのは、どこまで被害が及んでいるかを確かめるまで、新しい被害を出さないためだと考えられます。
停止が長引くかどうかは、調査の結果しだいです。

## ENEOSの対応

アプリは止まったままで、事実関係と影響範囲の調査が続いています。
利用者が押さえておきたいのは、続報がどこで発表されるかと、困ったときの問い合わせ先の2点です。
どちらも、偽の窓口にだまされないための大事な情報になります。

### サービス停止と調査

ENEOSは、事実関係、お客さま情報の漏えいの有無、影響の範囲を調査中です。
新しく知らせるべきことがわかれば、ウェブサイトなどで速やかに案内するとしています。

サービスの再開は、システムの安全性を確かめてからになります。
再開の見通しが立った時点で、同じくウェブサイトなどで知らせる方針です。
続報はENEOSの公式サイトのお知らせ欄を直接確認するのが確実です。

### 問い合わせ窓口

アプリについての問い合わせは、ENEOS公式アプリヘルプデスクの[お問い合わせフォーム](https://eneos-ss.app/contact/)で受け付けています。
フォームへは、メールやSMSのリンクからではなく、ブラウザで公式サイトを開いてたどるようにしてください。

偽のサイトは、本物とそっくりの見た目で作られることがあります。
自分で開いた公式サイトから進むことが、偽の問い合わせ窓口を避けるいちばん簡単な方法です。

## 利用者が注意すべき二次被害

漏えいの有無がわからなくても、二次被害はすでに起こりうる状況です。
有名なサービスが止まると、利用者の不安につけ込む詐欺の連絡が増えます。
ここでは、今回の件で届きそうな偽の連絡の例と、ENEOSの名前が狙われやすい背景を紹介します。

### ENEOSを装った偽メール・SMS・電話

ENEOSを名乗るメール、SMS、電話には注意が必要です。
ENEOS自身も、不正アクセスに便乗した不審な連絡に気をつけるよう呼びかけています。
偽の連絡は、アプリの再開やおわびなど、利用者が待っている話題を装い、リンクを開かせようとするのが特徴です。
今回の件で届きそうな偽の連絡の例を、次にいくつか挙げます。

- 「アプリ再開のため会員情報の再登録が必要」とリンクを送るSMS
- 「不正利用防止のためカード番号を確認」というメール
- 「おわびのクーポンを配布」と手続きに誘うメッセージ
- 担当者を名乗り、生年月日やカード情報を聞き出す電話

こうした連絡のURLや添付ファイルは開かず、個人情報やカード番号、パスワードも入力しないでください。
本当に必要な手続きであれば、公式サイトやアプリのお知らせでも同じ案内が出ているはずです。
もしリンクを開いて情報を入力してしまったら、カード会社への連絡やパスワードの変更をすぐに行いましょう。

### ENEOSグループで不正アクセスの公表が続いている

ENEOSグループでは、この1か月ほどで不正アクセスの公表が相次いでいます。
10月28日にはENEOS Power（[公式サイト](https://www.eneos-power.co.jp/)）が、ENEOSでんきなどのシステムからの個人情報の漏えいを発表しました。
11月2日には、ENEOSカーリースの委託先から最大8,500件の契約情報が漏れたと公表されています（[ENEOSの発表](https://www.eneos.co.jp/announcement/20261102.html)）。

これらと今回の件の関係は発表されていません。
ただ、ENEOSの名前に不安を感じる人が多い時期は、詐欺の連絡が届きやすくなります。
複数のENEOSのサービスを使っている人ほど、連絡の真偽を慎重に見分けてください。

## 今すぐやるべき対策

公式の続報を待つあいだにも、利用者が自分でできる備えがあります。
どれも数分で終わる内容で、漏えいがあった場合でもなかった場合でも、今後の被害を防ぐのに役立ちます。
アプリを使っている人は、上から順に済ませておきましょう。

### メールやSMSのリンクからログインしない

アプリが再開しても、メールやSMSのリンクから開いてログインするのは避けてください。
アプリは、スマートフォンにインストールしたものをそのまま使い、更新はApp StoreやGoogle Playから行います。

「再開しました」という案内を受け取ったときも、まずは公式サイトで同じ情報が出ているかを確かめます。
これだけで、偽のログイン画面に情報を入力する被害の多くは防げます。

### 同じパスワードを使い回していないか確かめる

ENEOS公式アプリには、メールアドレス、LINE、Apple IDのいずれかでログインします。
いずれの場合も、そのアカウントのパスワードをほかのサービスでも使っているなら、この機会に変えておきましょう。

アプリの情報が漏れたかどうかとは関係なく、使い回しは乗っ取りの大きな原因になります。
とくにメールアドレスのパスワードは、ほかのサービスのパスワード再設定にも使われるため優先して見直してください。

### クレジットカードの利用明細を確認する

アプリにクレジットカードを登録している人は、カード会社のアプリや会員サイトで利用明細を確認しておきましょう。
身に覚えのない請求があれば、すぐにカード会社へ連絡します。

カード情報が漏れたという発表は、11月25日時点ではありません。
それでも、明細を見る習慣があれば、万一のときに早く気づけます。
カード会社の連絡先は、カードの裏面に書かれた番号を使ってください。

### 詐欺サイトや詐欺SMSを止めるセキュリティソフトを入れる

偽のSMSやメールは、気をつけていても本物と見分けにくいことがあります。
うっかりリンクを開いてしまったときの備えとして、セキュリティソフトが役立ちます。

[ノートン 360](https://jp.norton.com/)は、詐欺サイトを見つけて危険なページを開くのを防ぐ「セーフウェブ」と、フィッシングの可能性があるSMSをAIで見分けて振り分ける「セーフSMS」を備えています。
1台から5台まで、パソコンとスマートフォンで使えます。
60日間の返金保証があるので、[ノートン 360で自分のスマホに合うプランを確かめる](https://px.a8.net/svt/ejp?a8mat=450Z77+1UOM2Q+3IBI+631SX)ところから始められます。

## 企業・業界の教訓

今回の件は、たくさんの人が毎日使うアプリを運営する企業にとって、ひとごとではありません。
不正アクセスはどの企業でも起こりうるため、起きたあとにどう動くかが問われます。
企業の目線と利用者の目線の両方から、学べる点を2つ挙げます。

### 「止める」判断と、代わりの手段の用意

ENEOSは、不正アクセスを検知した当日のうちにアプリを止め、その日のうちに公表しました。
同時に、現金やカード、タグ型EneKeyで給油できることを示し、利用者が立ち往生しないようにしています。

アプリを止めれば売り上げや利便性に影響が出ますが、被害が広がってからでは取り返しがつきません。
止める判断を早くすることと、止めたときに使える別の手段をふだんから用意しておくことは、セットで考える必要があります。

### 会員の多いアプリは、それだけ狙われやすい

会員が多いアプリほど、攻撃者にとっては魅力的な標的になります。
支払い機能やポイント、車の情報などが一つのアプリに集まるほど、守るべき情報も増えていきます。

利用する側も、「大手のアプリだから安全」と考えすぎないことが大切です。
必要のない情報は登録しない、使わなくなったアプリは退会する、といった小さな習慣が、万一のときの被害を小さくします。
